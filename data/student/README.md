# Student Domain Synthetic Dataset

Generated with fixed random seed 42 for reproducibility.

Files:
- students.csv: 20,000 student master records
- student_semester_records.csv: semester-level academic/financial records
- student_outcomes.csv: retention, dropout, placement and graduation outcomes
- enrollment_history.csv: 10 years x 10 departments of institutional enrollment history

Intended ML models:
1. Enrollment Forecast Model
2. Student Success Model

The data is synthetic and contains no real student PII.
